# EduVariant Generator

## Проблема
Підготовка індивідуальних варіантів завдань з математики та фізики для різних учнів забирає надто багато часу, особливо через необхідність ручного набору складних формул. Окрім цього, подальша перевірка робіт ускладнюється через відсутність автоматично згенерованих ключів з відповідями до кожного унікального варіанта.

## Рішення
Застосунок дозволяє створювати параметризовані шаблони завдань, на основі яких автоматично генерує унікальні тести для кожного учня з випадковими, але математично коректними числовими значеннями. Після генерації програма автоматично компілює умови завдань та ключі з відповідями у PDF за допомогою рушія XeLaTeX, забезпечуючи ідеальне типографське форматування.

## Цільовий користувач
Репетитори з математики та фізики (5–11 класи), викладачі та шкільні вчителі, які прагнуть автоматизувати процес створення індивідуальних домашніх, лабораторних і контрольних робіт.
