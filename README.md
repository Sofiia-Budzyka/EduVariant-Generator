# EduVariant Generator

EduVariant Generator – REST API для автоматичної генерації індивідуальних завдань з математики та фізики з компіляцією PDF через XeLaTeX та хмарною синхронізацією. Проєкт розроблено в рамках лабораторної роботи.

Посилання на живий URL (Deploy) Базовий URL API: https://eduvariant-api.onrender.com

Інтерактивна документація Swagger UI: https://eduvariant-api.onrender.com/swagger-ui/index.html

## Інженерні вимоги

### User Stories
* Як репетитор з точних наук, я хочу створювати параметризовані шаблони завдань із динамічними змінними, щоб миттєво генерувати унікальні варіанти тестів для кожного окремого учня.
* Як викладач, я хочу, щоб усі згенеровані PDF-файли автоматично синхронізувалися з моїм Google Drive, щоб я мав зручний доступ до матеріалів з будь-якого пристрою.
* Як розробник, я хочу, щоб важкі обчислення та компіляція документів відбувалися на віддаленому сервері, щоб мінімізувати навантаження на клієнта.

### Вимірювані обмеження
* **Performance:** Час повної генерації одного варіанта не повинен перевищувати 3.5 секунд для 95% запитів.
* **Availability:** Хмарний API-сервіс та база даних повинні мати Uptime не менше 99.7% на місяць.
* **Security:** Усі мережеві запити шифруються за протоколом TLS 1.3, а інтеграція з Google Drive використовує OAuth 2.0 без збереження паролів.

### Дизайн ендпоінтів
**Ендпоінт:** `/api/v1/variants/generate`
**Метод:** `POST`
**Заголовки:** `Content-Type: application/json`, `Authorization: Bearer <token>`
**Request:** `{"template_id": "math-geometry-60deg", "student_name": "Sofiia Budzyka", "cloud_sync": true}`
**Response (201 Created):** `{"status": "success", "variant_id": "var-8843", "pdf_url": "...", "sync": "completed"}`

## Тест-кейси

🔗 Тест-кейс 1: Успішна генерація та синхронізація

**Given (Дано):** Авторизований користувач із дійсним токеном OAuth вибрав наявний шаблон завдання та вказав коректні параметри. 
**When (Коли):** Користувач надсилає POST запит на `/api/v1/variants/generate`. 
**Then (Тоді):** Повертається статус 201 Created, PDF-файл успішно компілюється та зберігається у Google Drive користувача.

🔗 Тест-кейс 2: Валідація некоректних даних

**Given (Дано):** Користувач передає помилкові дані (максимальне значення параметра менше за мінімальне). 
**When (Коли):** Запит проходить через внутрішній валідатор на сервері. 
**Then (Тоді):** Сервер відхиляє запит зі статусом 400 Bad Request із детальним описом помилки; компіляція не запускається.

🔗 Тест-кейс 3: Помилка хмарної авторизації

**Given (Дано):** Термін дії токена OAuth 2.0 для зв'язку з Google Drive закінчився або доступ був скасований. 
**When (Коли):** Сервер успішно генерує PDF, але зазнає невдачі під час спроби завантаження файлу в хмару. 
**Then (Тоді):** Повертається статус 202 Accepted, файл зберігається локально, а користувачу видається повідомлення про помилку синхронізації.

## Інструкція із запуску

1. Локальний запуск (через Maven в IntelliJ IDEA) 

Для запуску проєкту локально переконайтеся, що у вас встановлено **JDK 17** (або новішої версії) та середовище розробки **IntelliJ IDEA**.

Склонуйте репозиторій: 
`git clone https://github.com/Sofiia-Budzyka/EduVariant-Generator.git`

Відкрийте IntelliJ IDEA та оберіть `File -> Open...`, вказавши папку склонованого проєкту. IDE автоматично розпізнає `pom.xml` та завантажить необхідні залежності.

Запустіть проєкт за допомогою вбудованого Maven-плагіну (на панелі Maven праворуч оберіть `Plugins -> spring-boot -> spring-boot:run` або виконайте в терміналі IDE):
`mvn spring-boot:run`
